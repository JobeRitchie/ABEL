 Full documentation is in README.md, next to this file. Open it in any text
 editor or view it on the project page. This file is a quickstart only, so
 there is one copy of the documentation to keep current rather than two.


 QUICKSTART (Windows)
------------------------------------------------------------------------------

 Double-click run_abel.bat. It creates a virtual environment, installs ABEL,
 runs a PySide6 self-test, and launches the GUI. Re-run it any time to update.


 QUICKSTART (manual)
------------------------------------------------------------------------------

     python -m venv .venv
     .venv\Scripts\activate          (Windows)
     # source .venv/bin/activate     (macOS / Linux)
     pip install -e .
     abel

 Optional dependency groups, also installable from the in-app Dependencies
 tab: [preprocessing], [gpu], [benchmarks], [clustering], [dev], [all].
 See README.md for what each one contains.
