ABEL

Active-learning Behavior Estimation and Labeling

Get started Cite ABEL View on GitHub

Version 0.24.0 · Windows · Python 3.10+

ABEL is a graphical user interface (GUI)-based, no-coding required platform for human-in-the-loop annotation and training of predictive models for behavior analysis. It adapts the frame-level active-learning approach to a clip-level pipeline with a built-in annotation platform. ABEL takes the user from raw pose-tracked data to refined exports in a single pipeline.

Alongside the supervised loop, ABEL includes a suite of data analysis, visualization, and validation tools for group-based analyses, graphing, statistics, and export of bout start and end frames for use with aligning fiber photometry data.

Getting started

Requirements

  • Windows
  • Python 3.10 or newer
  • Git
  • Microsoft Visual C++ 14.0 or greater. Get it from the Microsoft C++ Build Tools and select the Desktop development with C++ workload.
  • NVIDIA graphics and CUDA drivers (recommended)

Install

  1. Open a command prompt in the folder where you want ABEL, then clone the repository.

    git clone https://github.com/JobeRitchie/ABEL.git

  2. Double-click run_abel.bat. It creates a virtual environment, installs the app, and opens ABEL.

  3. Click Dependencies. If anything is missing, click Install All Dependencies. You only need to do this once.

To open ABEL later, double-click run_abel.bat.

Input data

  • Video in .mp4 or .avi format
  • Pose tracking from DeepLabCut or SLEAP, in .csv or .h5 format
